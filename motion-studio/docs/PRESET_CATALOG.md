## KineticHeadline

_typography_ — Oversized display type that enters glyph by glyph, can change into another word, and leaves through its own baseline.

**Effect.** A single typographic object that persists across scenes. Glyphs rise through a slot at the baseline (CharacterReveal), converge from wide tracking (TrackingExpansion), or fade. A later state swaps only the letters that differ while shared letters slide to their new places (MatchCut / TextScaleTransition).

**Timing.** enter: per-unit stagger (tight = 1.5f) over `base` (16f). change: letters that differ roll through their slot as glued pairs, old one slot above new (stagger `base` 3f, each over `base` 16f), while shared letters slide over `long` (24f). exit: per-unit stagger over `short` (10f).

**Easing.** Entrances ease out (.23,1,.32,1); exits ease in (the same curve reversed); rolls and slides ease in-out (.77,0,.175,1).

**Performance.** One <text> per glyph; measurement cached per string + style. Negligible per-frame cost.

**Anchors.** `@<id>.start`, `@<id>.end`, `@<id>.inkEnd`, `@<id>.firstEnd`, `@<id>.top`, `@<id>.center`, `@<id>.bottom`

## MaskedTextReveal

_typography_ — A supporting line of text that rises through its baseline as a line, word by word, or glyph by glyph.

**Effect.** Text appears from behind an invisible edge at its own baseline, so it reads as set into the layout rather than faded onto it.

**Timing.** by line: one move over `base` (16f). by word: words stagger by `tight` (1.5f). Exits leave through the same edge.

**Easing.** Out on entry, in on exit (theme curves).

**Performance.** Same renderer as KineticHeadline.

**Anchors.** `@<id>.start`, `@<id>.end`, `@<id>.inkEnd`, `@<id>.top`, `@<id>.center`, `@<id>.bottom`

## WordStack

_typography_ — A list that builds one word at a time: each new word rises in at the bottom and pushes the stack up.

**Effect.** Accumulation in type: a growing pile of items (tasks, tools, steps). Older lines settle back and leave through the top once the stack is full.

**Timing.** A word every `interval` frames (default 8); each rise and each push take `short` (10f).

**Easing.** Out curve for rises and pushes; exit uses the in curve.

**Performance.** One <text> per word.

## LineDraw

_geometry_ — A rule that draws on, can be drawn by a moving accent, can slide to a new place, and retracts.

**Effect.** Structure appearing as if ruled by hand: a hairline extends from an end or the centre, or trails a moving point so the point leaves the line behind.

**Timing.** draw over `long` (24f); retract over `base` (16f); moves over `long`. follow: no timing of its own, it is exactly as far along as the path.

**Easing.** Draw eases out, retract eases in, moves ease in-out.

**Performance.** One <line> per frame.

**Anchors.** `@<id>.from`, `@<id>.to`, `@<id>.center`

## GridAssembly

_geometry_ — A lattice of small marks that assembles into a visible system, and can be cleared by a passing accent.

**Effect.** Registration-style marks snap in across a grid in a deliberate order (from the centre, by rows, diagonally), establishing structure before anything else arrives.

**Timing.** Start times spread over `spread` frames in the chosen order; each mark takes `base` (16f). Disassembly: each mark leaves when the path passes closest, plus distance ÷ ripple frames.

**Easing.** Marks turn in a quarter turn while scaling in (out curve); leave scaling down (in curve).

**Performance.** rows × cols small elements; 60 marks cost well under a millisecond per frame.

| Param | Type | Default |
|---|---|---|
| `cols` | number | `6` |
| `rows` | number | `10` |
| `area` | object | `{}` |
| `mark` | "cross" \| "dot" \| "tick" \| "square" | `"cross"` |
| `size` | number | `14` |
| `stroke` | number | `2` |
| `color` | string | `"inkDim"` |
| `assemble` | object | _optional_ |
| `disassemble` | object | _optional_ |
| `keep` | "none" \| "corners" | `"none"` |
| `keepExit` | object | _optional_ |

**Example** (A 6 × 10 lattice of crosses assembling from the centre outward.):

```json
  "preset": "GridAssembly",
  "params": {
    "cols": 6,
    "rows": 10,
```

## Accumulation

_geometry_ — Lines, shapes, labels and outlined echoes crowd in on a lattice with accelerating density; a passing path can clear them.

**Effect.** Controlled overload. Everything snaps to one lattice and is drawn on, so the crowd reads as a system choking on itself rather than noise. Paired with a group freeze it stops dead; paired with a path it is undone in a ripple that follows the accent.

**Timing.** Arrivals between build.at and build.until; with "accelerate", the n-th of N arrives at at + span·√(n/N). Each draws over `base` (16f). Clearing: closest approach of the path + distance ÷ ripple (px/frame), over `short` (10f).

**Easing.** Draw-on eases out; un-draw eases in.

**Performance.** ~60 elements; layout precomputes every start and clear frame, so a frame is only arithmetic. Measured in docs/benchmarks.json.

| Param | Type | Default |
|---|---|---|
| `seed` | string | `"field"` |
| `area` | object | `{}` |
| `cols` | number | `6` |
| `rows` | number | `10` |
| `lines` | number | `18` |
| `rects` | number | `8` |
| `circles` | number | `6` |
| `labels` | string[] | `[]` |
| `labelSize` | number \| "micro" \| "caption" \| "body" | `"micro"` |
| `echo` | object | _optional_ |
| `build` | object | **required** |
| `clear` | object | _optional_ |
| `stroke` | number | `2` |
| `color` | string | `"ink"` |
| `dimColor` | string | `"inkDim"` |
| `dim` | number | `0.5` |

**Example** (A crowd builds with accelerating density over two seconds.):

```json
{
  "preset": "Accumulation",
  "params": {
    "seed": "example",
    "labels": [

```

- Echoes copy the first state of a KineticHeadline.

## Accent

_geometry_ — The one live element: a point that rides a motion path, can drive other layers, and lands with intent.

**Effect.** A single accent-coloured point moving through the composition. Other layers key off its path (lines it draws, elements it clears, irises it opens), so the accent visibly causes change instead of decorating it.

**Timing.** Entirely from its path keys; appear/vanish over `short` (10f).

**Easing.** Per path key (default in-out). A slight stretch along velocity at speed, never a bounce.

**Performance.** One element; path sampled twice per frame for velocity.

| Param | Type | Default |
|---|---|---|
| `path` | string | **required** |
| `size` | number | `28` |
| `shape` | "dot" \| "square" | `"dot"` |
| `color` | string | `"accent"` |
| `appear` | object | _optional_ |
| `vanish` | object | _optional_ |
| `sizes` | object[] | `[]` |
| `stretch` | number | `0.3` |

**Example** (The accent crosses the frame left to right and settles.):

```json

  "params": {
    "path": "example-pass",
    "size": 28
  }
}
```

## DirectionalWipe

_transition_ — A solid panel that travels across the frame to hand one scene to the next.

**Effect.** A deliberate hard edge replacing a cut. In "through" mode the frame is fully covered at the midpoint, which is where the outgoing layers should end and incoming ones start.

**Timing.** Over `long` (24f). Midpoint = at + duration/2: time the swap there.

**Easing.** In-out by default, so the panel accelerates through the cover and decelerates out.

**Performance.** One rectangle.

| Param | Type | Default |
|---|---|---|
| `at` | number \| string | **required** |
| `duration` | number \| "micro" \| "short" \| "base" \| "long" \| "hold" | `"long"` |
| `direction` | "left" \| "right" \| "up" \| "down" | `"up"` |
| `mode` | "through" \| "cover" \| "uncover" \| "edge" | `"through"` |
| `thickness` | number | `6` |
| `color` | string | `"ink"` |
| `band` | number | `1` |
| `ease` | string \| tuple | _optional_ |

**Example** (A full-frame panel passing upward; the midpoint is fully covered.):

```json

  "preset": "DirectionalWipe",
  "params": {
    "at": 10,
    "direction": "up"
  }
}
```

## BrandLockup

_brand_ — The verified Quiet Bands lockup (mark over wordmark) drawn from assets/brand, revealed without distorting it.

**Effect.** Resolves to the identity. The mark opens through an iris from a chosen point (often where the accent comes to rest) or rises into place; the wordmark rises through its own baseline. The mark is never split, outlined, stretched or recoloured per part.

**Timing.** mark over `long` (24f), wordmark over `base` (16f); start them a few frames apart so the eye lands on the mark first.

**Easing.** Out curves on both.

**Performance.** Two filled paths and two clip shapes per frame; nothing measured.

**Anchors.** `@<id>.center`, `@<id>.top`, `@<id>.bottom`, `@<id>.markCenter`

| Param | Type | Default |
|---|---|---|
| `x` | number \| string | `"center"` |
| `y` | number \| string | `"safe.cy"` |
| `width` | number | `420` |
| `color` | string | `"ink"` |
| `mark` | object | **required** |
| `wordmark` | object | **required** |
| `exit` | object | _optional_ |

**Example** (The lockup resolves: mark through an iris from its centre, wordmark rising after it.):

```json
{
  "preset": "BrandLockup",
  "params": {
    "mark": {
      "at": 4
    },
    "wordmark": {
```

## Common fixes

| Symptom | Cause | Fix | Found in |
|---|---|---|---|
| Elements survive a sweep and vanish later, when the accent lands somewhere else. | Clear times use the closest approach over the whole path, including where it goes after the pass. | Set `clear.window.to` (Accumulation) or `disassemble.window.to` (GridAssembly) to the end of the pass. | simplicity-is-a-viewpoint |
| Letters overlap mid-swap in a KineticHeadline state change. | Outgoing and incoming glyphs moved on different curves. | Fixed in the engine: changed letters roll as glued pairs (old exactly one slot above new) on one in-out curve. | simplicity-is-a-viewpoint |
| A rule sits on top of the next line as it rises. | The rule retracted after the next text started. | Retract structure at the moment the next beat begins, not after. | simplicity-is-a-viewpoint |
| The first half-second is black. | Everything starts at frame 0 from zero. | Pre-roll the opening layer with a negative time (e.g. `"at": "start-8"`) so frame 0 already shows it forming. | simplicity-is-a-viewpoint |
| QA lists a long still stretch under "holds" that was not designed. | A beat finishes earlier than the next one starts. | Start the next beat earlier or slow the current move; keep only holds you can name. | simplicity-is-a-viewpoint |
| WordStack lines stay visible after their exit. | Exit distance was fixed, but the stack clip spans every line. | Fixed in the preset: each line travels to the clip edge. | automate-the-coordination |
| Preview fails "dimensions" by one pixel. | 4:2:0 video needs even sizes; a 0.5× preview of 1350 px is 675. | Fixed in QA: scaled previews expect the even size. | automate-the-coordination |
| A final render reused a stale preview after code changed. | Preview validity was keyed on the project file only. | Fixed: previews are keyed on project hash + engine hash. | automate-the-coordination |
| "Circular references" between a path and a layer. | A path pins to a layer that also samples that path at layout. | Sample at render time: declare the param under `refs.renderPaths` in the preset. | simplicity-is-a-viewpoint |
| A time like "intro-a+4" fails or picks the wrong scene. | Scene ids may contain hyphens, which look like minus signs. | Fixed: the parser splits at the point where the left side is a known scene. | engine |

## Known limitations

- Text layers are single-line; set multi-line copy as several layers sharing a style with "like".
- Text measurement uses the browser at render; Node-side validation uses approximate metrics, so anchor positions in the storyboard are estimates.
- The synthesised sound bed is a placeholder: a few procedural voices, not music. Use an audio track with `src` for real music or voice.
- Voice mode cuts at measured pauses only; there are no word-level timestamps.
- Reference analysis measures cuts, motion and audio; it cannot identify typefaces or easing curves.
- Three.js is not installed: there is no real 3D. Depth is simulated with group cameras and per-layer parallax.
- Rendering is CPU-only by design (SwiftShader); roughly 6 fps for a busy 1080×1920 master on 4 cores.
- Remotion is free for individuals and companies of up to three people; larger teams need a Remotion company licence.
