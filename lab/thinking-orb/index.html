Interactive orb playground

<thinking-orb> · lab

A small visual experiment you can hold. Each orb is a few hundred dots drawn on a canvas, moving in one of nine patterns. Pick a pattern, drag the orb around, tune the sliders, and copy the markup for the look you made. It is an animation, not an AI: nothing you do here is sent anywhere or stored.

The art and the animation engine are thinking-orbs by Jakub Antalik (MIT licence, notice). Quiet Bands ported the React component to plain JavaScript and added the hold, drag and fling controls, which act on the animation’s own clock. Learn to build things like this →

How the controls work

  
    
    
  • Hold anywhere on the big orb to pause it.
    • 
    
  • Drag sideways to rotate; let go mid-swipe to fling it.
    • 
    
  • Keyboard: focus the orb, then use the arrow keys to nudge and Home to reset.
    • 
    
  • Pattern buttons switch between the nine states. Shaping morphs between circle, triangle and square.
    • 
    
  • Sliders change speed, density, dot size and settings for each pattern. Ink sets grey, cream or orange.
    • 
    
  • With reduced motion turned on, each orb paints one still frame, and a drag still turns it.
    •
