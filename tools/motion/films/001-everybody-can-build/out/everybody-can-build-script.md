# Film 001: EVERYBODY CAN BUILD. Final narration (Jay / Flighty voice)

The revision keeps the argument and the three locked lines. It loosens the rest into how Jay talks: short clauses, plain words, one honest aside, no hype vocabulary. Each line is generated as its own take and sequenced with designed pauses, so the timing is set by the real audio.

## Changes from the working script

- "Something that used to take a team can start with one person and a prompt" became "Stuff that used to take a whole team? One person and a prompt." It's how it would be said out loud: the question does the work.
- "that's crazy when you really think about it" became "that's wild, when you really sit with it." Same feeling, less filler.
- "Because nobody cares how fast you made something…" became "Nobody cares how fast you made it…". "Because" is dropped because the pause already implies it.
- "The real question isn't…" became "So the question isn't…". The "so" makes it a conclusion, not a slogan.
- The locked lines are kept word for word.
